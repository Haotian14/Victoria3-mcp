> **最重要的口径纠正**：顶栏第二行从左到右是 GDP → 识字率 → SoL → 人口 → **激进派** → **效忠派** → 恶名；**顶栏没有国库**。旧资料里被当作“国库”的 9.67M、19.0M、45.6M、62.0M 等，实际都是**激进派**；被当作“周结余”的 26.7M、30.7M 等，实际是**效忠派**。周结余在顶栏第一行右侧（金币图标）。

> 三局不能混日期：宝宝巴士是主档；adv1 是同一 UP 的高难度失败线；adv2 是 1878–1920 的另一局。

**读法/缺口**：

- 1865 年建造力 `?`：6600 s 被“和谐”面板遮挡；旁证 6570 s（1865-02-21）为 1054/1054，不入表。
- 1841 年 74/309：同年 4 月还是 207/298，年内因战争/缺料大幅闲置；不是建造暂停。
- 1843 年用 1843-10-28 的年末帧（263/265、SoL 9.0）；1843-09-18 受认可当天的里程碑是 264/264、SoL 9.5，两者日期不同，不要混。
- 旧表的 45.6M/62.0M 等“国库”是激进派；本表不再把它们放进国库列。

**读法**：v6-120m 的人均 GDP 在 1836–1838 甚至高于 UP，但 SoL 从 8.71 一路降到 7.85；建造力在 1836–1839 只有 UP 的 1/5–2/3，1841–1842 因 UP 战争/缺料大幅闲置反而高于 UP，1843 后又落到约 2/3。不是“GDP 不够”，是“GDP 没转成建造力和消费”；新 run 的 `input_recovery` / `sol_recovery` 就是冲这两条。

**国库不要对比**：UP 的国库在宝宝主档基本读不到；v6 的国库是自家 `money` 字段。旧表“UP 45.6M/49.8M/62.0M”都是激进派，不能拿来和 v6 的 42.2M 比。

## 5. 数据限制

- **不插值**：三份表都是帧读；读不到写 `?`，不补数。
- **宝宝主档**：国库只有 1841 年一次（黄金储备 1.29M / 金库余额 -135K）；1840 年只有 4 月；1865 年建造力被面板遮挡；1839 年旧资料称国库 2.31M，本帧无法复核。
- **adv1**：42 年都有 12 月帧；国库只有 4 个 tooltip；1856 是太平天国清廷口径。
- **adv2**：43 年都有帧；主表“激进派（第5金额）”不是国库；真实储备只有 5 个 tooltip 读数；建造力 5 年因年末队列为空写 `?`，同年更早值见 `up_yearly_adv2_exact.md` 第 2 节。
- **旧文档要改**：`up_timeline.md`、`up_yearly.md` 旧版、`up_visual_data.md` 里把第 5/6 项当“国库/周结余”的读数都要按本表纠正。
- 逐帧证据在 `logs/bili_video/frames_yearly_baby/`、`frames_adv1/yearly_work/`、`frames_adv2/yearly/`；三份原始表在 `docs/up_yearly_baby_exact.md`、`up_yearly_adv1_exact.md`、`up_yearly_adv2_exact.md`。
