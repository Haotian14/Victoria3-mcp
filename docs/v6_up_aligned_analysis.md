## 结果与差距出现的时间

观测中，国库最低4.291M，期末31.714M；信用消耗、利息、财政in_default、破产、借款统一惩罚均为0。按周巡检在最高速下并非严格每7天，相邻观测日期最大间隔15天；原始日期均保留。统一5→4来自鸦片让步，不是借款。终点实际军队为200步兵、50炮兵、50预备征召，预备征召未动员。税级Medium、合法性100。

期末GDP106.79M、SoL8.23、识字率31%，建造已用/基础74.99/279.94；政府建造用量0、私营74.99，政府队列0项。仍未受认可，承认JE为0/200。最长连续立法空窗62个月（1840.11→1845.12），没有达到≤6个月的要求。1838、1843的建造基础能力达标，实际使用量均未达标；1843年12月GDP103.64M、SoL7.79，也未过验收。

终点直接读取行政力提示框：产出11,156.08，结余−5,392.45；已整合人口消耗12,415、机构3,993、将领100、国有建筑40。提示明确给出 **+48.3%税收浪费和+48.3%政府分红浪费**。1843.5的独立只读探针也读到−5,137.38行政力和46%浪费。

`strategy.json` 的 `admin_max_total_levels=40` 与开局全国已有203级不相容；`construction.candidates()` 要求现有等级小于此全国上限，所以整个run没有补行政。这会持续损失收入和政府分红，收紧可用于建造的现金流。月收入同时受私营建造报销等流量影响，表中110K收入下降不能全额归为某一项税损。

## 2. 基础建造力追上了，允许的政府项目没有跟上

本轮500条财政样本中，财政紧急模式0条、政府建造暂停0条。旧run“暂停后从未恢复”的问题没有再次出现；但新增队列仍受持续周盈余约束，常常只能容纳0–2个政府项目。

终点可直接复算：余额28,209.52/周，取85%预算为23,978.09；每个25点项目按最低单价1,000和25%余量报价31,250/周，允许新增项目数为0。国库31.7M不会被这个算法当作持续收入使用。实际建造因而长期维持50–100点，基础能力却已约280。

UP1838–1839帧中明确承担−94K至−104K/周的赤字，我们遵守非负现金流护栏，两者的投资节奏有政策差异。需要先修收入损失，再用实测项目净成本校准报价和安全余量；单纯加建造部门不能填补这部分使用缺口。

定位：[项目额度算法](../src/agent/strategy/budget.py#L48)。1839.8.18独立队列探针确实看到两个活动工具厂、政府使用49.41点、私营74.43点，证明中期确有政府施工，并非仅界面暂停标记错误。证据：`logs/v6-up-aligned-live-probe.json`。

## 3. 法律显示值误当生效法，提前加了政府工资

`observe.laws()` 从活动法律列表读取 `Law.GetLawType`；实机证明它在制定期间显示目标法。1839.8探针显示目标“佃农”，而 `Law.GetActiveGroupLaw.GetLawType` 仍为“农奴制”。

这个问题已经影响支出决策：1836.3和1839.11，重商主义都还在制定，工资控制器却因读取到目标法而把政府工资从Low切回Medium。首轮失败后，1837.1又切回Low。第二次切换附近，政府工资从1839.11的52.4K升到12月61.6K/周；其他成本也在变化，不能把整个月余额差都算作工资单一效应。

报告已经按制定标记保留此前生效法，并与终点 `GetActiveGroupLaw` 读取一致；原始 `law_keys` 不回写。运行中的策略输入尚未修复，以保留本轮完整对照。

定位：[法律观测](../src/agent/observe.py#L288)、[工资判断](../src/agent/strategy/budget.py#L175)。

## 4. 法律承诺签成后，概率门槛和未履约状态没有闭环

| 环节 | UP宝宝主档 | 本轮 |
|---|---|---|
| 重商主义 | 1836.1.4启动，1840.4前完成 | 首轮1836年失败；第二轮1840.11月初首次确认生效 |
| 佃农 | 1839.12.15完成 | 1839.10月初已确认生效，比UP早 |
| 经济干预 | 1840.1.17启动，1843.6.20完成 | 1843.11.1签成普鲁士承诺，到1846仍未启动 |
| 公立学校 | 1843.6开始制定 | 到1846未启动，当前仍缺支持 |
| 受认可 | 1843.9.18 | 到1846仍0/200 |

早期经济干预没有政府支持，西/普/法在5K/周报价内拒绝，俄方不支持目标法。1843.11终于签成普鲁士“柏林协议”，但终点法律单检查点成功10%、推进0%、受阻27.2%，模型通过率仅12.43%，低于生效承诺和六个月兜底的15%门槛。因此签约没有转化为立法。

终点条款提示累计26次未履约，阈值是6次；条约双方冻结读数为大清0、普鲁士1。当前 `records()` 只查本国是否冻结，仍把它标成active并用来去重，没有处理对方冻结和具体条款未履约。资金条款仍显示大清→普鲁士5K/周；西班牙重商承诺也仍支付5K/周。这是**条约未履约**，与财政 `in_default=False` 是不同状态。

承诺目标存在时，`plan.decide()` 先把全部法律选项收窄到这一项；目标不可推时，六个月兜底也没有可用替代项。终点政府是士大夫59.3%+乡村民众10%，独裁制名额已满，二者均受保护；小市民仅4.3%且边缘化，实业家0.3%。不能简单假定“再拉一个支持集团”就能立即解决。

定位：[承诺状态识别](../src/agent/treaties.py#L51)、[15%门槛](../src/agent/data/strategy.json#L120)、[选项收窄](../src/agent/strategy/plan.py#L70)。证据为run日志和终点条款读回。

## 5. 科研、消费品和承认外交没有形成视频中的循环

大学1836–1839年末均为0，1840年2级，1841年至终点只有3级。终点每周实际创新53.03，上限96.84；研究顺序相同，但证券交易所到1838年才结束，殖民到1841年、经验主义到1843年底才结束，中央档案馆到1846仍在研究。冲刺期大学排在部门、食品、贸易中心、铁矿之后，且上限5级；在有限政府额度下长期轮不到。大学主要提供创新/资格，不能将其数量直接换算成识字率。

全国纺织厂全程16级，UP所说的新增40厂没有兑现；终点牧场已增至63、铁矿17、工具厂7，但铁价70/基准40，工具69.72/40，肉52.5/30，仍有明显供给约束。期末预算预测政府分红仅559/周；UP“多45K分红”是作者预期，不是可直接套入我们预算的实测回款。收入选择还要核验所有权、实际净利润与行政浪费。

承认JE到1841.7才首次记录激活。终点5份在生效条约中，**offer_embassy条款为0**；没有复现UP的六份大国使馆。代码仍用普通外交行动关键词寻找使馆，真实条约实现目前只覆盖法律承诺。原版进度脚本每份相关使馆加1/月、传统主义扣1/月；40%识字率只是额外加分条件。我们既没完成经济干预，也没做成使馆，单等识字率不能追上UP1843年的承认。

本轮消费税终点只征服务税，与视频相符；不能把茶/酒/鸦片税作为这次差距的原因。鸦片选择仍为让步避战，与宝宝档禁烟并防守的路线有差异。

## 6. 开局兵营连续扩建与视频误读

用户追问后回看原视频，1981秒明确为“转移单位”，骠骑兵填入50；不是新招50炮兵。旧stage1/stage2把这段误记为“200步兵+50炮兵+50征召”，进而建议先补炮，现已撤回。原帧保存在`logs/video_alignment/baby_1981_military_verify.png`。UP1838秒口述兵营先排5级，主线排60建造部门、贸易中心与每州大学；不能把现有军队转移等同于新造50个炮兵兵营。

本轮`handle_military()`为达到已配置的50炮兵目标，每月最多补2营。从1836.2.1到1838.9.2共新增50次，三年分别16、24、10次，占用有限政府项目额度。代码虽给经济项目留一个位置，但把军队目标过早变成开局连续补建，进一步挤压大学/消费品。最终军队目标与开局施工优先级应分开处理，不再以旧视频误读为理由。此处为本轮明确的复现偏差；新增项目造成的具体GDP损失尚未做对照测量。

## 后续修复顺序

1. 先修真实生效法观测；把新法律自动带来的机构官僚需求纳入评估，修正40级行政总上限，并在现金护栏内处理行政缺口。
2. 承诺签约前核验签成后的立法可执行性；补双方冻结/条款未履约检测，设置有限的重谈、支持调整或替代路线，不能一边支付一边空窗62个月。
3. 先整编既有军队、按威胁安排补建，不把50炮兵目标当开局连续新建任务。在真实预算恢复后校准小批建造报价，给大学、消费品和上游设可兑现的次序；记录政府分红与投资池流量，核验新增厂能否补财政。
4. 补真实使馆条约及承认进度核验，再做短测和120个月复验。整体未过验收，仍不进入300个月。

这些证据定位了具体分岔与机制；每个修复能追回多少GDP，需要固定开局的对照实验测量。开局也未证明与UP完全相同：本存档GDP108.5M、基础建造22；视频设置阶段约86.0M→83.6M、基础40→39。对比只用宝宝主档；进阶上/下为另一条连续战役，不混入本十年。1840原帧置信B，未据其单行作强归因；1846.11帧在本轮区间外，不作外推。
