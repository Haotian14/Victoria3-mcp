# 三个视频与 v6 的进度对齐（2026-10-25）

> 后续已按用户要求重开实测：[v6_reopen_verification.md](v6_reopen_verification.md)。一个政府项目在盈余下恢复成功；西班牙目标法承诺实际生效，重商主义已开始制定。本报告是此前的诊断快照，自动策略代码仍待接入实测流程。

结论：**差距是真实的，但不是起手建造太慢。财政版在1837年把政府建造停住，此后没有恢复；政治路线从第一条法律就没复现视频。** 旧300个月版则是一直支出、最终破产。两者都没有实现视频里的“建造—收入—改革—恢复建造”循环。

本次回看本地三个原视频的关键片段、画面、转写，并复核当前代码与正式120个月日志；没有重新播放完整六小时视频，没有启动游戏、修改策略代码或另跑一局。原始视频在 `logs/bili_video/`，本次补帧在 `logs/video_alignment/`。

## 3. 第一处分岔：停建之后缺少可负担的恢复

正式日志在1837.1.6首次暂停政府建造：现金10.73M、收入362.9K/周、支出396.7K/周，赤字33.8K；其中政府建造商品128.6K/周。暂停后盈余约80–104K，但恢复规则要求加回暂停前整笔商品成本的110%，约141.45K/周。这个条件长期不成立，直到1846.1.1都没有恢复。479条财政样本中431条处于政府建造暂停；这不是431周。

代码证据：`src/agent/runner.py:fiscal_guard()`中的`resume_construction_cost`；日志只有一次`PauseConstruction`成功，没有`ResumeConstruction`成功。其间顶栏仍有50–100点，政府建造商品为0，不能据此称政府投资正常。

**视频有暂停，也有明确恢复。** 宝宝主档2756秒（1840.7.7）右上写“已暂停”，字幕“好有一些存款之后”；2759秒（1840.7.28）已恢复294/294。进阶上1040秒（1842.12.2）政府建造暂停，1505秒（1844.12.17）已恢复287/287。不能从这些离散帧推算完整暂停时长，但足以排除“他也一直停建”。

证据：[宝宝暂停](../logs/video_alignment/baby_2756.png)、[宝宝恢复](../logs/video_alignment/baby_2759.png)、[进阶暂停](../logs/video_alignment/adv1_1040.png)、[进阶恢复](../logs/video_alignment/adv1_1505.png)。

下一次实现应先估算单个项目/小批政府建造的**净周成本**，缩减活动队列后按持续盈余分批恢复，继续保留8周现金、执行前预算、禁止借款/违约硬闸。不能用40M存款为长期负周结余背书，也不能要求一次恢复所有旧负荷才允许动工。暂不假定这个修复单独就足够达到200/250点；收入增长也必须补上。

## 4. 更早的分岔：视频的法律承诺没有真正接入

| 阶段 | 宝宝主档实际操作 | 我方实际结果 |
|---|---|---|
| 第一条法 | 开局与西班牙起草条约，指定重商主义承诺并给转账；1836.1.4开始重商主义 | 先推专职警察；重商主义虽在配置第一位，却没有启动 |
| 土地/经济法 | 佃农1839.12.15完成；经济干预1840.1开始、1843.6.20完成 | 1837年底前佃农完成后没有接上经济改革，月初统计立法空窗最长97个月 |
| 支持与外交 | 根据目标法拉乡村民众/小市民入阁；再次请求目标法承诺 | 期末士大夫+乡村民众占满当前政府名额；重商、寡头、经济干预均0%通过率 |
| 承认 | 废广州体系后激活承认JE，签大国使馆；1843.9.18受认可 | 广州体系仍在，承认链未打通；不能靠继续等识字率补救 |

**这不只是参数太保守，是动作能力缺口。** `runner.handle_diplomacy()`把`law_commitment`放进`Actions.diplomatic_actions()`的普通外交行动关键词匹配；但游戏的`common/treaty_articles/20_law_commitment.txt`把它定义为需要`law_type`输入的条约条款。现有Actions有读/退出条约及回复提议，没有起草、指定法律条款、配置转账、提出并核验生效的完整流程。本轮外交成功计数只有5次，日志均为改善关系，没有成功法律承诺/贸易特权/使馆条约。配置中写了关键词不等于完成了视频操作。

视频证据：[西班牙条约草稿，1670秒](../logs/video_alignment/baby_1670.png)、[重商主义+5%提示，1895秒](../logs/video_alignment/baby_1895.png)。先补目标法承诺并核验生效/成功率变化，再评估是否需要绕寡头、养实业家等替代路线。不能用农本主义兜底代替视频经济干预路线而仍称精确复现；也不能为凑“6个月”强推0%法律。

## 5. 第三个视频告诉我们的事

进阶下展示的是上集积累四十年的后期经济。1881.8.22（1200秒）能直接读到真实黄金储备110M、周结余+1.66M，同时建造2066/4209；1920收官是9869/18863，已用与基础仍不相等。不能把“造出上限”当作一直有相同产出，也不能把后期储备条件套回1836。

1912.8.17（7226秒）法律面板显示合作社所有制、累进税制、公立学校、义务小学、养老金等；专职警察已生效，秘密警察只是失败尝试。这解释后期收入分配与SoL提升的路线，**不证明这些法在宝宝局1843年已经通过**。公司吞吐同时增加投入，换高级建造PM也需要先补玻璃/钢/工具；不能只照抄公司名称或最终建造上限。

证据：[1881真实财政提示](../logs/video_alignment/adv2_1200.png)、[1912法律面板](../logs/video_alignment/adv2_7226.png)。

## 6. 对齐规则和下一步顺序

1. **先补实际能力**：条约起草与目标法承诺闭环，以及小批政府建造恢复；成功必须核验条款生效、法律概率、实际建造/预算变化，不能只记按钮执行成功。
2. **再补收入和材料循环**：视频2370秒明确“拉40纺织厂”；2365秒说预期多45K分红，属于作者估算，不能当作国库已经增加45K的实测。我国应记录政府分红、税收、投资池转移和所有权，按实际净收入选择厂；木铁工具短缺同时处理。不能把任意工厂利润自动视为国库自偿。
3. **政治路线以宝宝主档为主**：重商→佃农→经济干预→公校，承认前置/使馆同步；不把进阶篇主动失败条件加入默认路线。当前`opium_war=avoid`主动让步，与主视频禁烟并守关键州的路线不同；若要完整复现，还需保护与防守能力，不能只改事件选项。原1836统一5→4已证实是鸦片让步，不是借款。
4. **先短诊断，再120个月**：首先观察首个赤字后能否在现金/非负预算约束下恢复小批建设，开局目标法是否真正启动；无进展立即保留诊断，避免再空转十年。120个月仍按原财政、承认、GDP、SoL与法律空窗验收，未通过不进300个月。

补充口径：顶栏第5/6金额是激进派/效忠派，不是国库；周结余来自顶栏第一行预测值，我方日志使用`GetWeeklyBalance`，存在显示时点/预测口径差异，不能拿单帧差值直接认定某项支出。UP真实国库只接受预算面板/提示框证据。精确快照以[up_yearly.md](up_yearly.md)及本报告为准，旧分阶段稿的数字或跨档法律不可覆盖新核验。
