> **关键校正 1（时间轴）**：按画面右上角日期逐帧核对，**0–1875s 游戏日期一直是 1836-01-01，且处于暂停**；1875s 左右才解除暂停，**1900s 到 1836-01-04**。因此“0–1900s”实际上是**开局暂停设置局**，并不包含 1837 年。本文第 2.7 节用 1900–2200s 的快进画面补 1836–1837 的里程碑数值，并明确标注“快进/超出 0–1900s 窗口”。
>
> **关键校正 2（ASR）**：转写错字很多，本文对不确定词一律标“推断”。最重要的一处是：1527s 的“贝伊”并不是某个小国；画面显示的是 **英国/东印度公司** 的 25 年利益协议（右侧“大不列颠的条款”，英国国旗），详见 2.5。

## 结论速览（5 条）

1. **0–1900s 几乎全是暂停设置**：0–1875s 日期停在 1836-01-01，1875s 左右解除暂停，1900s 才到 1836-01-04；真正的 1836–1837 数据在 1900–2200s 快进段。
2. **财政三件套**：中等税级 + 只收服务税 + 政府/军队工资压到最低。政府工资约 **-29.8K/周**、军队约 **-25.6K/周**；国家支出从 **-167K/周** 降到 **-143K/周**（t190 画面）。不去追 **897K** 未征税额：江西一省 69.0K、征收率 89%，回本要 **16.7M** 前期投入。
3. **建造冲刺**：4 个州 × 15 级 = **60 级建造部门**；广东贸易中心 **10 级**、兵营 **5 级**、每州大学 **1 级**。建造力从 **0/40** 起步，1836-01-04 已用 **39/39**，1836-03-23 **100/100**，1836-08-30 **183/183**，1837-09-21 **202/202**。
4. **科技/法律**：科技走 **证券交易所 → 殖民/经验主义 → 化学漂白 → 铁路 → 水管锅炉 → 炼钢 → 机械工具 → 造纸**；第一法是 **重商主义**（靠西班牙“法律承诺 +5%”），不是佃农；1836 年内再把佃农/老农议题接上。
5. **外交/军队**：给 8 大列强 5 年贸易特权；与俄罗斯做商品输送（木 1000、硬木 120、铁 17）+ 保证独立；收 **10 个朝贡国** 解锁“附近研究”；整编现有军队，口述200营、50骠骑、50农兵，超编删90，战时军饷切中等。**2026-10-25原帧复核：1981秒是“转移单位”，单位名为骠骑兵，旧“50炮”解读错误；不能据此推出新增50炮兵兵营。** 代价是 SoL 从 9.6 一路降到 7.9。

## 8. 最终 5 条 bullet

1. **0–1900s 是暂停设置局**：0–1875s 日期停在 1836-01-01，1875s 左右解除暂停，1900s 才到 1836-01-04；1836–1837 的数值必须用 1900–2200s 快进段补。
2. **财政三件套**：中等税 + 只收服务税 + 政府/军队工资最低；政府 -29.8K/周、军队 -25.6K/周，支出 -167K → -143K/周；897K 未征税直接放弃（回本要 16.7M）。
3. **建造冲刺**：4 州 ×15 =60 级建造部门；广东贸易中心 10、兵营 5、大学每州 1；建造力 1836-03-23 100、1836-08-30 183、1837-09-21 202。
4. **科技/法律**：证券交易所→殖民/经验主义→化学漂白→铁路→水管锅炉→炼钢→机械工具→造纸；第一法重商主义（西班牙 +5%），不是佃农。
5. **外交/军队**：8 大列强 5 年贸易特权，俄罗斯商品输送（木 1000/硬木 120/铁 17）+保证独立，10 个朝贡国拿“附近研究”；军队 200+50+50，战时军饷中等；代价是 SoL 9.6 → 7.9。
