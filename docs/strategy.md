## 建造（construction.py）

**每级每周利润 = 产出 − 投入（本国市场价）− 工资**，除以建造点数 = 每点建造力的回报。

- 工资：游戏里每级每周工资 ≈ 雇员数 / 1000 × 建筑的 `GetWageRate` × 约 1.1（职业混合）。
  核对：山东玻璃厂 10 级 5 万人、工资率 120 → 模型每级 660，游戏 `GetLastWagesExpenses` 每级 756。
- 增加值核对：山东纺织厂 8 级，模型产出每级 2,663（按市场价、满员），游戏 `GetTotalProductionValue` 17,355 / 8 = 2,169，
  差约 20%（本地价与吞吐修正），量级可靠。
- 工资率：州里已有同种建筑时用它自己的（农场比工厂低得多），否则用州里建筑的中位数。
- **劳动力**：州里可招的人（失业 + 自给农民）不够 3 级的雇员就不建。没有这条时，边疆小州（阿尔泰、图瓦）
  因为工资率低、账面利润最高而排在最前，但根本招不到人。
- 未并入的州 ×0.5，与市场不连通的州不建；基础设施超用 ×0.6；同类建筑招工不到 80% ×0.3；
  产品市场价低于基准价 60% ×0.5；同一建筑本月每多排一级 ×0.5（价格会被自己压下去）。
- 每月最多新排 4 个政府项目，队列短于 3 个或建造力没用满时才排；赤字时国库撑得住才排且最多 1 个。
- 优先：建造部门（造价只有 25 点，没有在建的就加一级）；税收浪费超过 5% 时加政府行政机构（官僚不足的信号）。

## 生产方式（production.py）

按与建造相同的利润式挑每组的方式。差距 10% 以内不换（避免价格波动来回切）；投入在本国市场上
没人卖（卖单 0）的方式不选。每月轮流检查 12 个建筑（按等级从大到小），读列表很费往返。

## 研究（research.py）

`tech_priority`：城镇规划（铁框架建造部门、+5 建造）→ 车床（工具、玻璃生产方式）→ 竖井开采（铁、煤）→ 理性主义 →
官僚体系 → 炼钢 → 机械工具 → 大气式蒸汽机 → 铁路 → 集约农业 …… 缺前置时先研究前置；表走完按时代补位。

## 法律（politics.py）

`law_route`：干预主义 → 按人头征税 → 佃农制 → 保护主义 → 宗教学校 → 慈善医疗 → 地方警察 → 商业化农业 → 私立学校 → 自由放任。
同一时间只推一条。每月对路线上的每条目标读游戏的预计概率（推进 / 有利事件 / 受阻 / 辩论）和各集团的立法立场：
- **通过率** = 先攒满 3 次推进、而不是先攒满 3 次受阻的概率（辩论当作原地踏步）；低于 `politics.min_pass`（0.5）不推，
  因为失败后两年不能再提；
- 没有可推的，且路线上靠前的目标**只差支持者**（唯一障碍是「立法成功概率高于 0%」，或可推但通过率太低），
  就把支持它、影响力最大的在野非边缘集团**加进**政府（只加不减；合法性 ≥ 60、政府不超过 4 个集团、
  12 个月最多改组一次），本月不推法律，下个月按新政府重算。缺科技、被别的法律挡住的目标不为它改组。

## 大清专题（2026-10 调研 + 实测）

**为什么十年推不动一条法律**：立法基础成功率 = 政府里**支持**这条法律的利益集团的影响力之和（+ 支持的运动 + 君主）。
大清开局政府里只有士大夫（影响力 49.6%），他们除了警察、国教之外不支持任何改革，所以几乎所有法律的
`IsValid(Law.StartEnacting)` 都卡在「立法成功概率高于 0%」。只能直接推的：地方警察、专职警察、国教。
**瓶颈是政府组成，不是法律顺序。**

1836.1.1 实测利益集团（影响力 / 是否在政府）：士大夫 0.496 在朝；军队 0.150；儒生 0.142；乡村民众 0.098；
文人 0.067；小市民 0.035、工会、实业家边缘化。合法性 100。

各集团对改革的态度变化（游戏 `common/ideologies` 算出，正 = 支持，负 = 反对）：

| 法律 | 士大夫 | 军队 | 儒生 | 乡村民众 | 文人 | 小市民 | 前置 |
|---|---|---|---|---|---|---|---|
| 佃农制（废农奴制） | −1 | 0 | 0 | +1 | +2 | 0 | 无 |
| 职业军队 | −1 | **+3** | 0 | +1 | 0 | 0 | 已有军事操练 |
| 地产投票 | 0 | 0 | 0 | 0 | +1 | 0 | 已有民主 |
| 农本主义（离开传统主义） | 0 | 0 | 0 | +1 | 0 | +1 | 浪漫主义 |
| 经济干预 | 0 | 0 | 0 | 0 | 0 | +3 | 须先废农奴制 |
| 人均税制 | −1 | +1 | 0 | +1 | 0 | +2 | 货币本位制，且不能是传统主义 |
| 集会权 | −1 | −1 | −2 | 0 | +1 | −1 | 无 |

硬性前置（`common/laws`）：农奴制挡住经济干预、自由放任、教会学校、公立学校；传统主义挡住人均税制、商品化农业；
贸易保护要证券交易所。

由此得出的路线：
1. **改组政府**：士大夫 + 军队 + 乡村民众（合计约 74%）。士大夫对「农本主义、地产投票」中立，不会拖后腿。
2. 先推「零反对」的：职业军队（军队 +3）、地产投票（要文人在朝）；研究浪漫主义后推农本主义，离开传统主义。
3. 拉文人、乡村民众推佃农制，废掉农奴制；之后才谈经济干预和人均税制。
4. 失败或取消后两年不能再提（wiki Laws），所以推之前要看成功率，不能盲试。

社区共识（多为旧版本，只作参考）：开局有近百万未实现税收（税收能力不足），但别急着大建行政机构
（缺纸、要工资），先扩原材料再扩制造业；广州一口通商有 −25% 贸易能力，要领导集团须先废除；
关闭边境别早废（新教传教、太平天国事件）；大学 15–25 级提升研究；鸦片战争前最好与俄国结防御盟约。

改组政府已打通（`POST /gov/reform`，原理见 `docs/bridge.md`），规则见上面「法律」一节。
注意游戏判定的立法立场与静态意识形态表不完全一样（含集团领袖的意识形态）：例如军队反对地产投票，
乡村民众支持佃农制。程序一律以游戏的 `IsEndorsingLawEnactment` / `IsOpposingLawEnactment` 为准。

### 1.13 打法落地（2026-10-22 联网调研）

来源：NGA「大清怎么玩啊」「大清现在咋打鸦片战争」、B 站《大清开局的困境与发展路径》《大清极速科技流》、
PTT「大清开局破局法」、Paradox Wiki China/Qing、贴吧科技/识字机制。核对 1836.1.1 开局存档：
已有 `academia`、`centralization`、`tech_bureaucracy`、`international_trade`、`manufacturies` 等 24 项科技，
**大学开局即可建**。

已写进代码的规则（`data/strategy.json` 的 `country_profiles.CHI`）：

- **科技**：浪漫主义 → 货币本位制 → 经验主义 → 证券交易所 → 辩证法 → 中央档案馆 → 银行 → 机床链。
  前四项都是开局一步可研的时代 1 科技；中央档案馆是时代 2，实测单独一项要五年，不能放最前。
- **法律**：佃农（废农奴制；实测 100%）→ 农本主义（离开传统主义；乡村民众支持）→ 人均税制
  （需货币本位制；军队 / 乡村民众支持）→ 教会学校（早期教育机构上限 3）→ 公立学校 → 职业军队 →
  经济干预 → 技术治国 → 贸易保护。**地方警察不进自动路线**：它通过后警察机构吃掉大量官僚，
  实测税收浪费从 0% 跳到 26–30%，把行政机构全补一遍也压不回去；等中央档案馆 / 税制稳定后再手动推。
- **大学**：产出创新、不产出商品，经济账看不见，单独按人口大州铺 30 级；`dialectics` 后切哲学系
  （创新 +50%），`analytical_philosophy` 后切分析哲学系（+100%）。
- **行政**：按各州 `CalcTaxCapacityUsage − CalcTaxCapacity` 缺口补，最多 2 个/月；不再可着一个州堆。
- **教育机构**：识字率 ≈ 10% × 机构等级 + 2% × 财富等级；公立学校前先把教育拉到 2 级。
  机构不存在（法律没到）时报错并锁一年。
- **州法令**：人口 ≥ 1000 万的前 2 个州开「促进社会流动」（教育机会 +25%、资质 +25%）；
  基础设施超用最严重的 1 个州开「道路养护」（+10% 建造速度）。
- **建造部门**：木材/布料价格超过基准 1.25 倍时先不扩；扩不动时钱会堆着，下一轮再按价格放开。
- **鸦片危机**：1.13 社区反馈「和英国签防御同盟」会被撕条约。没有军队 / 外交自动化时，
  `opium_war=avoid` 选让步，避免 1836 年被战争打崩；想硬打改成 `fight`。
- **事件**：runner 以前从不调用 `Actions.events()`，游戏按默认选项自动答。现在每月开始和推进时间时
  每秒检查一次：立法检查点优先「推进 / 通过」，其余按 `EventOption.GetDesc` 的「增加 / 减少 + 好坏名词」
  逐句打分，默认选项只加半分。

- **外交**：每月对俄 / 法 / 普轮换改善关系（`increase_relations` 是持续协定，已生效就不再点，
  否则会把它关掉）；自动回复提议：防御同盟 / 保障独立 / 贸易协定接受，要求 / 割让 / 赔款 / 投资权 /
  治外法权 / 拉拢拒绝。鸦片战争本身由事件策略默认避战。
- **研究队列**：当前研究还在跑、队列空时，把优先表里的下 1–2 项排进去，科技完成后的空窗由游戏接上。

**runner 现在自动化的事**：税级、法律与改组、研究（含队列补位）、建造（含建造部门 / 行政 / 大学）、
生产方式、事件、机构、州法令、外交提议与改善关系。**仍未自动化**：贸易路线与关税、公司、军事、
日志决议、消费税、工资档位——这些动作已经打通、可由 MCP `act` 手动发，但没有稳定的自动策略。

## 预算（budget.py）

只调税级：每周赤字且国库撑不过 30 周 → 加一级（最多到高税）；结余超过收入的 25% 且国库超过储备上限的 80% → 减一级（最低到低税）。

教训：
- **开支要能养得起**：建造部门每级每周吃木材布料加工资，规模要按收入定，不能看结余为正就加。
- **生产方式会自我反转**：自己一产出，那种商品就跌价，「最优」翻回去；切换还有适应期减产。要大门槛 + 长冷却。
- **模型看不见的产出别碰**：建造部门的产出是建造点数，不在商品账里。
- 大清前十年 GDP 增长主要靠建造与农业，法律几乎推不动（农奴制、利益集团反对），科技约两年一项。
