# adv2 进阶档 每年一行精确年度表（1878–1920）

来源：`logs/bili_video/BV1NvYf6FEEM_480p.mp4`（852×480，约 9390 s）。本表只取 adv2 原版战役；8880 s 之后的片尾 RA MOD 黑场/MOD 展示不进入本表。日期一律读画面，不插值。

## 0. 口径与重要更正

- 顶栏第二行从左到右：**GDP → 识字率 → SoL → 人口 → 第 5 金额 → 忠诚者 → 恶名**。GDP 与人口已逐帧核对，未看反（例：1920 年 GDP 3.9B、人口 743M）。
- 顶栏第一行从左到右：官僚力 → 权威 → 影响力 → 补给船 → **周结余（金币图标）**。
- 按题目口径，本表 `国库` 列抄的是**顶栏第 5 个金额**。经 `game/gui/topbar.gui` 核对，该位置绑定的是 `Country.GetNumRadicals`，即**激进者人数**，不是金币储备；1915 年后该数值在画面中转红，本表只抄读数，不解释为债务/负储备。
- 真正的国库/储备只在预算 tooltip 或财政面板出现，见文末附表，未混入主表。
- `建造力` 取右上角 `当前/上限`；某帧建造队列为空或计数未显示时写 `?`，并在第 2 节给出同年最后可见值。
- 置信：A = 日期、建造力、GDP、识字率、SoL、人口、第 5 金额、周结余均可直接读；B = 建造力缺失或借用同日帧，或周结余大数字末位受压缩影响；C = 关键字段不可读（本表无 C 行）。

## 4. 五条关键发现

1. **覆盖完整**：1878–1920 每年都有画面，没有整年缺失；共 43 行。1914、1915 两行在边界复核后从 7740 s/7920 s 改用了更晚的 7770 s（1914-11-30）和 7950 s（1915-11-20）。
2. **长期增长**：GDP 从 290.2M（1878）到 3.9B（1920），约 13.4 倍；人口 484M→743M；SoL 8.7→30.2；识字率 34.0%→99.9%；建造力当前值 2488→9869、上限 18,863。
3. **“国库”列其实是激进者**：`topbar.gui` 中第 5 金额绑定 `Country.GetNumRadicals`，不是金币储备。旧资料里的“国库 99.5M→2.14K”与本表 126M→2.14K 同源；主表按题目口径原样抄第 5 金额，真实储备另见第 3 节（最高读到 1.66B，1913 年）。
4. **建造力台阶**：上限从 1878 年的 2,488 升到 1920 年的 18,863；1888 年上限跳到约 8.5K，1897 年跳到约 17.4K，1902 年峰值 20,009 后回落到 16.8K 左右。1882/1885/1887/1904/1907 年末帧建造队列为空，故写 `?`。
5. **财政在战争期恶化**：周结余多数年份为负，1900 年是唯一明确为正的年末读数（+82.2K）；1917 年后从 -5.21M→-13.9M→-22.6M→-27.2M（1917→1920），同期 GDP 仍从 3.1B 升到 3.9B。法律线：1894 自由派法律包 → 1898 法团国家/种族隔离 → 1900 养老金 → 1901 妇女选举权推进 → 1912 终局法律包。
